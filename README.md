## Bobur Bunyodjonov

Web developer from Uzbekistan. I build production applications end to end — React / Next.js on the
front, NestJS or Fastify with Prisma and PostgreSQL behind it, shipped with Docker on a VPS or Vercel.
A lot of my recent work treats Telegram as a first-class surface: Mini Apps, bots and payments.

### What I'm building

| Project | What it is |
|---|---|
| [university-awdms](https://github.com/BoburBunyodjonov/university-awdms) | Academic workload management for a university department — formula-driven hour calculation, validated assignment, Excel reporting. NestJS + Prisma + React monorepo. |
| [flash-card (WordSwipe)](https://github.com/BoburBunyodjonov/flash-card) | Swipe-based vocabulary app with SM-2 spaced repetition. pnpm monorepo: Fastify API, React web app, Telegram Mini App, admin panel. |
| [online-invitation](https://github.com/BoburBunyodjonov/online-invitation) | Wedding invitation SaaS — order via Telegram bot, admin publishes a personalised page, guests RSVP. Next.js 16 + Prisma. [Live](https://online-invitation.uz/) |
| [kichikakademiya](https://github.com/BoburBunyodjonov/kichikakademiya) | Kindergarten landing page with Telegram-delivered enrolment leads. React 19 + Vite + MUI. [Live](https://kichikakademiya.vercel.app) |
